# WorkMax Support

WorkMax is a community-supported, pre-1.0 project. Public support is provided on
a best-effort basis and does not include a response-time guarantee.

## Before asking for help

1. Read the [README](README.md), especially prerequisites, configuration, and
   the current repository-state notes.
2. Run `make doctor` and the smallest relevant verification target.
3. Search existing GitHub issues for the same symptom.
4. Remove credentials, tokens, personal data, private URLs, and proprietary
   content from logs and examples.

## Where to ask

- Use the bug-report issue form for a reproducible defect.
- Use the feature-request issue form for a proposed enhancement.
- Use `support@workmax.app` for account, billing, or other private product
  support that is not a security vulnerability.
- Follow [SECURITY.md](SECURITY.md) for suspected vulnerabilities; never post
  them publicly.

Include the WorkMax version or commit, operating system and architecture,
relevant sanitized configuration, exact reproduction steps, expected behavior,
actual behavior, and the verification commands you ran. Maintainers may close
requests that are incomplete, out of scope, or cannot be reproduced.
