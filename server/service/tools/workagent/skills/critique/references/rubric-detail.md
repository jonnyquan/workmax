# 评分标准详解(每维度 1-10 分)

> SKILL.md 给出 5 维度的检查问题。本文档给出每个分段的判断标准 +
> 常见失分点。当评分时拿不准 7 还是 8,回这里查。

---

## 1. 目标契合度(Goal Fit)

| 分数 | 标准 |
|------|------|
| 9-10 | 每个元素都服务于用户陈述的目标,**零冗余**。读者一眼明白核心信息。 |
| 7-8 | 主要信息到位,有少量"为了好看"的元素稀释焦点 |
| 5-6 | 能看出方向,但执行偏移了 — 例如目标是"说服管理层"却做了"科普" |
| 3-4 | 与陈述目标只在表层相关,实际产物在解决另一个问题 |
| 1-2 | 跑题或答非所问 |

**常见失分**:
- PPT 目标是"内部汇报",做成了对外宣传风格
- 评审产物是"短剧分镜",生成了完整脚本
- 用户说"简洁",产物每页塞 200 字

---

## 2. 视觉/语言层级(Hierarchy)

| 分数 | 标准 |
|------|------|
| 9-10 | 视线沿设计者意图自然流动,信息获取零摩擦 |
| 7-8 | 主次清晰,偶有 1-2 处层级模糊 |
| 5-6 | 能分出标题和正文,但中间层级混乱 |
| 3-4 | 信息平铺,没有明确的视觉/阅读入口 |
| 1-2 | 混乱,读者不知道先看哪里 |

**常见失分**:
- 标题与正文字号对比 < 1.8 倍
- 颜色 / 粗细 / 大小 没建立 3-4 个清晰层级
- 留白没有引导视线
- "眯眼测试":眯起眼看,层级模糊 → 失分

**针对文字产物**:
- 核心观点埋在第 3 段才出现
- 列表混用层级深度 4+
- 一段超过 5 句话不分段

---

## 3. 细节执行(Craft Quality)

| 分数 | 标准 |
|------|------|
| 9-10 | 像素级精确,对齐、间距、颜色、字体无任何瑕疵 |
| 7-8 | 整体精致,有 1-2 处微小问题 |
| 5-6 | 基本对齐,但间距不统一,颜色使用不够系统 |
| 3-4 | 明显的对齐错误、间距混乱、颜色过多 |
| 1-2 | 粗糙,看起来像草稿 |

**视觉产物失分点**:
- 没用统一的间距系统(8pt 网格 / 4 倍数)
- 颜色 > 4 种(功能性多色如 status 标签除外)
- 字体家族 > 2 种
- 边缘对齐误差 > 2px
- 文字溢出 / 截断

**文字产物失分点**:
- 错别字 / 标点错误 / 中英文混排空格不一致
- 数字 / 单位 / 日期格式不统一
- 引用格式混乱
- 列表样式跨段不一致

---

## 4. 功能性(Functionality)

| 分数 | 标准 |
|------|------|
| 9-10 | 每个元素服务于目标,删掉任何一个都会变差 |
| 7-8 | 功能导向明确,有少量可删减的装饰 |
| 5-6 | 基本可用,有装饰性元素分散注意力 |
| 3-4 | 形式大于功能,用户需要努力寻找信息 |
| 1-2 | 完全被装饰淹没,失去传达能力 |

**Eraser test**(橡皮擦测试):
> 假设你能删掉产物里的任何一个元素。如果删掉某个元素后产物没有变差,
> **它本来就不该在那里**。

**常见失分**:
- 头图 / 配图与内容无关
- "装饰性" icon 在每个标题前重复出现
- CTA 不在最显眼位置
- 信息密度与载体不匹配(PPT 太密 / PDF 太稀)
- 出现"因为好看所以加"的元素

---

## 5. 创新性(Originality)

| 分数 | 标准 |
|------|------|
| 9-10 | 令人耳目一新,在体裁内找到了独特表达 |
| 7-8 | 有自己的想法,不是简单的模板套用 |
| 5-6 | 中规中矩,看起来像模板 |
| 3-4 | 大量使用 cliché(渐变球代表 AI / emoji 装饰 / 编造 stats) |
| 1-2 | AI slop 全集 |

**AI slop 红线**(踩任一即扣到 5 以下):
- 紫色 → 粉色 → 蓝色全屏渐变
- 圆角卡片 + 左 4px accent border
- 标题前的 🚀 ⚡️ ✨ emoji 装饰
- SVG 画的人物 / 场景 / 物品 imagery
- "10,000+ happy customers" 类编造数据
- 编造的用户评价 / 名人名言
- Inter / Roboto / Fraunces / Space Grotesk 烂大街字体
- 凭空发明的颜色(没有品牌依据)

**针对文字产物**:
- "在当今快节奏的社会中" / "随着技术的发展" 开头
- "不仅...而且..." / "赋能" / "闭环" / "下沉"
- 三段式排比凑字数
- 结尾"让我们一起..." 号召

---

## 综合分计算

```
overall_score = round((goal_fit + hierarchy + craft + functionality + originality) / 5, 1)
```

不要加权。让用户自己决定哪维度对当下场景最重要。

## verdict 写作

**好的 verdict**:
- "目标对齐但视觉粗糙"
- "创新足,细节差"
- "商务调性正确,信息密度过高"
- "AI slop 严重,建议重做"

**坏的 verdict**(避免):
- "整体不错,有提升空间"
- "完成度高,值得一看"
- "做得很用心"
- 任何超过 30 字的"评论员语言"
