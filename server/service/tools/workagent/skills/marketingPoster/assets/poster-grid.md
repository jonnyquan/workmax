# Marketing Poster Grid

> Reference for poster layout archetypes. The agent picks ONE based
> on the user's `offer` + `cta_style` from question_form. Each
> archetype is structurally pre-decided so the agent doesn't reinvent
> the visual hierarchy on every turn.

## 5 archetypes

### 1. Headline-dominant
- 60% of canvas: oversized typography statement
- 25%: visual support / product
- 15%: CTA + small print
- Best for: brand awareness, statement campaigns, `cta_style=aspirational`

### 2. Product-hero
- 50%: product photography (central or rule-of-thirds)
- 30%: headline + supporting copy
- 20%: CTA strip
- Best for: launch, `offer=launch`

### 3. Discount sticker
- Center: massive percentage / dollar amount
- Periphery: product + brand mark
- High color contrast (red on white / yellow on black)
- Best for: `offer=discount`, `cta_style=urgent`

### 4. Editorial split
- Diagonal or 50/50 vertical split
- Left/top: hero image; right/bottom: copy block
- Implies considered, premium positioning
- Best for: `offer=event`, `cta_style=informative`

### 5. Multi-element grid
- 4–6 small visual elements + one anchor copy block
- Higher information density
- Best for: events with multiple sponsors / programs / dates

## Aspect ratio × archetype

| Ratio | Recommended archetypes |
|-------|----------------------|
| 1:1 (Instagram) | 1, 3 |
| 9:16 (Story) | 1, 2 |
| 1.91:1 (X / Facebook) | 2, 4 |
| 4:5 (IG portrait) | 2, 3, 5 |

## Anti-patterns

- 4+ font families on one poster
- CTA buried below visual fold
- Headline AND product trying to share dominance (split focus)
- Generic stock-photo emotion (smiling people, raised hands at sunset)
