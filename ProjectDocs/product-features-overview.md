## 0. 一句话定位

> **想清楚 · 做出来 · 卖出去。**

**WorkMax 是一个「会干活」的桌面 Agent 平台：你出想法，它出成品。**

别人家的 AI 给你"看起来对的文字"，WorkMax 给你**可核查、可交付、能变现**的成品——一篇能直接发的稿子、一份没错数的表格、一套能上线的带货图文。一句话归类：**不是聊天框，是产出流水线；不是脑图软件，是会干活的脑图。**

「想清楚 → 做出来 → 卖出去」是整份文档的骨架，也是 WorkMax 的闭环。两条旗舰正好卡在两端，中间靠可核查的底座把「做出来」做稳：

| 闭环三步 | 谁来扛 | 在本文 |
|---|---|---|
| 🧠 **想清楚** | 脑图思维画布（旗舰一） | §2 |
| ⚙️ **做出来** | Writer / Work / Media / PPT 底座 | §4 |
| 💰 **卖出去**（且卖得稳） | 帮你赚钱·变现场景库（旗舰二）+ 护城河 | §3、§5 |

## 1. 人最关心的，我们放在最前面

大部分工具的文档从"架构、能力、插件"讲起。我们不这么干。我们先回答一个问题：**你用 WorkMax，能得到什么结果？**

以下是绝大多数人最在意的四类结果，我们把它们前置成"特色功能"——其中**赚钱排在第一位**。

| # | 你想要的结果 | WorkMax 给你的 | 依赖底座 |
|---|---|---|---|
| 💰 1 | **赚到钱** | 变现场景库：带货文案、短视频脚本、图文矩阵、知识付费讲义、数据代做…一键产出可售卖的成品 | Writer / Media / Work / PPT |
| ⏱ 2 | **省下时间** | 一个想法 → 一批成品；脑图拆解后多线程并行执行，10× 吞吐 | Agent Kernel 多线程 |
| 🎓 3 | **专业可信** | 不可变快照 + 引用/证据绑定 + 原创性核查，内容可追溯、不抄袭、敢署名 | 证据合同 / 写作完整性 |
| 💡 4 | **灵感不卡壳** | 脑图画布发散→收敛，节点一键派发给 Agent 落地 | 脑图思维画布 🟡 |

> 💰、⏱、🎓、💡 这四个 emoji 会贯穿全文，帮你快速定位"这个特色服务哪类诉求"。

下面两节，先展开两条**旗舰特色**（脑图思维画布、帮你赚钱），再给出支撑它们的**底座能力**与**护城河**。

## 2. 旗舰特色一：脑图思维画布（Mind Canvas）🧠💡 🟡

> **一句话：左边一张会生长的脑图，右边一群会干活的 Agent。你想清楚每一步，它替你做完每一步。**

当前产品里，用户和 Agent 的入口是对话（架构文档原文：*"Conversation 只是协作入口"*）。脑图画布把"入口"从一维对话，升级成**二维的可视化思维空间**——你不必在对话框里把一整件事讲清楚，而是在画布上把它**拆清楚**。

### 2.1 三层结构：发散 → 收敛 → 执行

| 层 | 你做什么 | 画布做什么 |
|---|---|---|
| **① 发散层** | 自由丢想法、关键词、链接、素材 | 节点自由排布，支持图片/链接/片段附件 |
| **② 收敛层** | 框选归类、连线、定优先级 | 一键"生成大纲"：把散点组织成层级树，自动去重补全 |
| **③ 执行层** | 点亮某个叶节点 → 选择"派发给谁" | 节点**实体化**为 Project/Artifact：写作派给 Writer、表格派给 Work、配图派给 Media、讲义派给 PPT |

关键体验：**脑图上的每一个叶节点，都能长成一个可交付的成品。** 整张图就是一张"生产排程"——你可以让 12 个叶节点并行跑，睡一觉起来收获 12 份成品。

### 2.2 为什么它不只是"画图工具"

| 普通脑图软件 | WorkMax 脑图画布 |
|---|---|
| 画完导出图片，然后呢？没了 | 画完一键**派发执行**，节点变成品 |
| 节点是死文本 | 节点是**活对象**，可绑定证据、引用、数据源 |
| 只服务"想" | 同时服务"想 + 做 + 验" |
| 单人思考 | 节点背后是真在干活的 Agent |

### 2.3 它如何融入现有架构（不空谈）

脑图画布不是另起炉灶，而是给现有平台加一个**新入口 + 一种可视化编排**：

- **作为 Desktop 的一等入口**：与"对话"并列，画布即 Project 的可视化视图（🔵 复用现有 Project/Thread/Turn 状态机）。
- **作为可视化的 Scenario Pack**：一张完整脑图等价于一个声明式编排——节点的连线即任务依赖，叶节点的"派发类型"即所选 Skill/Plugin（🔵 复用 §8 Scenario Pack 机制，**不授予额外权限**）。
- **导出能力**：脑图 → 大纲 → 喂给 Writer 的 `outline` 模式；脑图 → 任务清单 → 多线程 Turn 并行（🔵 复用现有 idempotent/lease 机制保证可靠）。

> 💡 这条特色直接命中"灵感不卡壳"和"省下时间"两类诉求，并为"帮你赚钱"提供规划入口（先在画布上规划一个内容矩阵，再批量产出）。

## 3. 旗舰特色二：帮你赚钱（变现场景库）💰 🟡

> **一句话：WorkMax 不只帮你写字，还帮你把字变成钱。**

我们把你"能卖钱"的内容场景，做成一组**开箱即用的变现场景库**。每一个场景都是"一个想法 → 一批可上架/可发布/可交付的成品"的流水线，全部建立在 Writer / Media / Work / PPT 真实能力之上。

### 3.1 变现场景库（首版）

| 场景 | 产出物 | 能帮你赚什么 | 底座能力 |
|---|---|---|---|
| **带货文案 & 电商广告套件** | 标题/卖点/详情页/主图文案/多版本 A/B 素材 | 电商成交、投流转化 | Writer + Media + 电商广告 Scenario Pack |
| **短视频/直播脚本批量** | 口播稿、分镜、挂车文案、多平台改写 | 创作者流量分成、带货佣金 | Writer（write/translate/summarize）+ Media |
| **图文矩阵（小红书/公众号）** | 选题脑图 → 一稿多发 → 去重改写 → 配图 | 平台流量、商单广告 | Writer（revise/humanize）+ Media + 批量 |
| **知识付费：课程讲义 & PPT** | 大纲 → 讲义稿 → 排版 PPT → 配套资料 | 课程售卖、付费社群 | Writer + PPT Agent |
| **数据代做（副业）** | 清洗/分析/图表/公式交付，单元格级可追溯 | 接单平台、自由职业 | Work Agent（analyze/clean/chart/formula） |
| **研究报告 / 咨询交付物** | 引用核查的研究报告 + 配套数据表 | 知识付费、咨询交付 | Writer + 研究能力 + Work |
| **多语种出海内容** | 翻译 + 本地化改写 + 母语化润色 | 跨境电商、海外自媒体 | Writer（translate/humanize） |

> 这些不是凭空想象——"电商广告套件""合同条款审查"等 Scenario Pack 已在架构文档 §20 中作为业务扩展示例出现。本特色做的是把它们**重新组织成"赚钱视角"**并补齐流水线。

### 3.2 "赚钱"为什么需要 WorkMax 的护城河

赚内容钱的人最怕三件事：**抄袭翻车、数据出错、引用造假**。一旦翻车，账号封禁、商单违约、口碑崩盘——直接断收入。WorkMax 的底座恰好是这三件事的解药：

| 赚钱路上的雷 | 别的 AI | WorkMax |
|---|---|---|
| 内容查重/抄袭 | "看起来是原创" | 🎓 写作完整性 + 原创性核查 |
| 数据/数字出错 | 拍脑袋编数 | 🎓 Work Agent 单元格级证据 + 确定性校验 |
| 引用/事实造假 | 编造来源 | 🎓 不可变快照 + 来源/证据绑定，**搜索片段不被当作可信引用** |
| 多份成品质量飘忽 | 每次靠运气 | 🔵 版本化 Skill/Checker，结果可复现 |

> 一句话：**用 WorkMax 产出的内容，你敢署名、敢交付、敢收费。** 这是"帮你赚钱"能成立的根基——不是生成得多，而是生成得**可靠**。

## 4. 底座能力矩阵（特色背后的真本事）🔵

旗舰特色不是空中楼阁。下面是它们脚下、已部分落地的真实 Agent 能力。每个 Agent 都是独立的 **Domain Plugin**，拥有自己的模式（mode）、工具、校验器和导出器。

| Agent 领域 | 模式 | 擅长产出 | 导出 |
|---|---|---|---|
| **Writer Agent** 🟢 | write / revise / outline / review / humanize / cite / summarize / translate | 文稿、改写、润色、引用核查、翻译 | Markdown / DOCX / PDF |
| **Work Agent (ExcelGPT)** 🟢 | build / analyze / clean / chart / formula / explain | 表格、数据分析、清洗、图表（analyze/explain 只读） | XLSX |
| **Media** 🟢 | 14 项官方 Skill + 程序化 Critique | 配图、设计资产、视觉审查 | 图片 / 资产包 |
| **PPT Agent** 🟢 | 预览（Alpha） | 演示文稿线程创建与续写 | PPTX（路线中） |
| **Legal / Research / Presentation** 🟡 | 规划中 | 合同红线、研究报告、品牌演示 | — |

**平台级横切能力**（让上面的 Agent 可靠、可扩展、可计费）：

- **Agent Kernel** 🟢：准入/幂等/积分冻结、Lease/Fencing/取消/对账、SSE 回放——保证"睡一觉收获 12 份成品"时不会丢任务、不会重复扣费。
- **Desktop 模型路由** 🟢 Partial：Local∥Official 偏好与本地 endpoint/Keychain 配置（bridge alpha.7 + Models UI）；**Local 推理执行**仍 🟡。
- **Scenario Pack** 🔵：声明式业务编排（如"学术引用审查""月度经营分析"），只预填输入/技能/交付物，**不授予任何权限**。
- **Capability Provider / Connector / Effect Executor** 🔵：受审核的工具、外部连接器、外部动作状态机——支撑"派发执行"与未来第三方生态。

## 5. 差异化护城河（为什么是 WorkMax）🎓

> 市面 AI 工具卷"谁写得快"，WorkMax 卷"**谁交付得稳**"。

| 维度 | 通用 AI 助手 | WorkMax |
|---|---|---|
| 内容可信度 | 给"看起来对"的答案 | 🎓 **claim → source → revision 证据链**，可核查 |
| 网络来源 | 把搜索片段当引用 | 🎓 **不可变网页捕获**，快照即证据，URL 失效也不怕 |
| 数据严谨 | 编数字 | 🎓 单元格级血缘 + 确定性校验 |
| 可靠性 | 刷新就丢 | 🟢 幂等 Turn + 事件游标回放，断线可续 |
| 数据主权 | 全在云端 | 🟢 **Desktop 唯一客户端**，数据所有权在你手里 |
| 可扩展 | 封闭 | 🔵 插件式平台，预留第三方生态（Phase 6） |

> 这条护城河是"帮你赚钱"能长期成立的理由：**翻车一次的损失，远大于慢一点的成本。**

## 6. 两条旗舰如何落在架构上（给工程师看）

本节把"特色"翻译成"架构改动"，证明它们不破坏现有地基、而是顺势扩展。细节以架构基线文档为准。

| 旗舰特色 | 架构落点 | 复用 | 新增 |
|---|---|---|---|
| **脑图思维画布** | Desktop 新增"Canvas"入口 + 可视化 Scenario Pack 视图 | Project/Thread/Turn 状态机、idempotent/lease、Scenario Pack 权限模型 | Canvas Slot、节点→Artifact 实体化、画布→大纲/任务导出 |
| **帮你赚钱（变现场景库）** | 一组预置 Scenario Pack + Skill Pack | Writer/Work/Media/PPT Domain Plugin、证据合同、Checker | 变现视角的场景目录、批量/去重/多平台分发流水线 |

**两条铁律不变**（来自架构文档 §6.4 / §10）：

1. 🟢 **WorkMax Desktop 是唯一用户客户端，Go Server 是唯一后端**——新特色只在这两个表面内生长，不恢复任何独立 Web/Admin 客户端。
2. 🎓 **不可变快照与证据合同不可绕过**——脑图节点实体化、变现场景产出，都必须经过同一个 Resolution → Immutable Snapshot → 证据绑定流程，没有"特权通道"。

## 7. 事实分级与路线

为避免把愿景说成现状，下面给每条特色的成熟度与建议落地阶段（阶段命名对齐架构文档 §22 的 Phase 0–6）。

| 特色 / 能力 | 状态 | 建议阶段 |
|---|---|---|
| Writer / Work / Media Agent 底座 | 🟢 已落地（部分） | Phase 1–2 |
| Desktop Local∥Official 模型设置 | 🟢 Partial（配置+UI；无 Local 推理） | Phase 0–1 |
| 证据合同 / 不可变快照 / 写作完整性 | 🟢 已落地（部分） | Phase 2–3 |
| 脑图思维画布（发散/收敛） | 🟡 规划中 | Phase 3 |
| 脑图节点→Agent 派发执行 | 🟡 规划中 | Phase 3–4 |
| 变现场景库（带货/短视频/图文矩阵） | 🟡 规划中 | Phase 4 |
| 知识付费讲义 & PPT 流水线 | 🟡 规划中（PPT 当前 Alpha） | Phase 4–5 |
| 第三方变现场景 / 插件市场 | 🟡 远期 | Phase 6（需先满足隔离/签名/配额/审计） |

> 规划项的先后顺序遵循一个原则：**先把"做得稳"做扎实（护城河），再放大"做得快、赚得到"（旗舰特色）。** 翻车的变现不如不变现。
